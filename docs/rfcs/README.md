# RFCs

Decision records for **cross-cutting** changes to AMDS — a new token category, a breaking change, a new architectural pattern, dropping a supported platform version. Small additions (one component, one screen) use a [Proposal issue](../../.github/ISSUE_TEMPLATE/proposal.md), not an RFC.

## Process (see [`../governance.md §8`](../governance.md))

1. Copy [`0000-template.md`](0000-template.md) → `NNNN-short-title.md` (next number).
2. Open a PR with the RFC. Comment period ≥ 1 week.
3. Core team records the decision (`accepted` / `declined` / `deferred`) in the file and merges it.
4. Accepted RFCs are implemented in follow-up PRs that link back here.
