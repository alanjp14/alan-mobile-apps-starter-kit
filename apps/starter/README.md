# starter

The AMDS **reference app** — a runnable showcase of the design system (theme, core components, state widgets, a smooth shared-axis transition). Runs on no backend.

## Run

The `lib/` and `pubspec.yaml` are here; the platform folders (`android/`, `ios/`, …) are generated by Flutter:

```bash
cd apps/starter
flutter create --org com.example --project-name starter .   # first time only — generates android/ ios/ etc.
cd ../..
dart pub get                                                 # resolves the workspace
cd apps/starter
flutter run
```

> `flutter create .` will not overwrite the existing `lib/` or `pubspec.yaml`.

## What it demonstrates

- `AmdsTheme.light()` / `.dark()` with a live theme toggle in the app bar
- `AmdsButton` (variants, sizes, loading, press-spring), `AmdsTextField`, `AmdsCard`
- `AmdsAnimatedCount`, `AmdsFadeSlideIn` (staggered entrance), `AmdsStatusChip`
- `AmdsSkeletonList`, `AmdsEmptyState`, `AmdsDialogs.confirm`, `AmdsSnackbar`
- `AmdsOfflineBanner` on the detail screen
- `amdsSharedAxisTransition` between Home → Detail (reduced-motion aware)
- text-scale clamp to the AMDS 0.85–2.0 range
